## 0.5.0 — Portfolio MVP release candidate

### Added

- FastAPI analyst web UI and API.
- Bounded O2C process-analytics tool layer.
- Deterministic stage-comparison and grouped deterioration logic.
- Local business-context retrieval.
- Deterministic what-if scenario simulator.
- Scripted free mock backend and optional OpenAI Responses API backend.
- Session response-lineage state and bounded analyst preferences.
- Tool/model observability and usage/latency metadata.
- Controlled Scenario V1 Marketplace bottleneck benchmark.
- Seven behavior-level evaluation cases and deterministic trace checks.
- Semantic evaluation rubric and optional LLM-as-Judge path.
- Dockerized local deployment.
- One-command portfolio demo launcher.
- Demo readiness and prompt/tool transparency endpoints.
- Presentation mode, process flow, KPI cards, evidence tables, and tool-path UI.
- Custom scenario assumption control.
- Stateful causal follow-up using prior mock investigation results.
- Markdown and JSON report export.
- CLI demo fallback.
- CI-generated demo artifacts.
- BA requirements, AS-IS/TO-BE case study, traceability matrix, and portfolio report.

- Repository landing page now positions the project as O2C analytics plus an AI process-improvement agent.
- Prompt guidance now requires a bounded pilot scope, success metrics, dependencies, and human decision gate for process-change recommendations.
- Mock prompt routing accepts common paraphrases of the main portfolio question.
- CI workflows avoid duplicate feature-branch push/PR runs.
- Policy retrieval ignores heading-only matches.
